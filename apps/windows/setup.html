FOON Windows

معاينة للموقع الأصلي محلياً · Original website local preview · Aperçu local

تحتاج قاعدة MySQL محلية مجهزة بمخطط FOON وحساب موجود. لربط الطلبات، اختر ملف جهاز صادر من خادم الاختبار؛ يجب تطابق معرفات المتجر والفرع والمستخدم في القاعدتين.

Requires a provisioned local MySQL database. Optional device enrollment links supported orders to staging; local tenant, branch, actor and catalog IDs must already match the cloud.

الربط اختياري؛ لا توجد مزامنة دون ملف تفعيل.

يحمي Windows إعداد الاتصال بحسابك. بيانات قاعدة MySQL تحتاج حماية القرص والنسخ الاحتياطي الخاصة بها.
