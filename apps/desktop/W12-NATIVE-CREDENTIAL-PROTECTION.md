# FOON Windows W12 — حماية مفاتيح الجهاز داخل Rust

**الحالة: نموذج تنفيذي Native، وليس دمجًا نهائيًا في تسجيل الأجهزة.**

## ما تم إضافته

- `src-tauri/src/windows_secret_store.rs`: وحدة Rust تعمل على Windows فقط. تستخدم `CryptProtectData` و`CryptUnprotectData` مع `CRYPTPROTECT_UI_FORBIDDEN` ضمن نطاق مستخدم Windows الحالي. لا تستعمل وضع `CRYPTPROTECT_LOCAL_MACHINE`.
- لا توجد أوامر Tauri في الوحدة، ولا تمرير للمفاتيح إلى JavaScript أو WebView.
- `DeviceSecret`: يحتفظ بالبيانات مؤقتًا في ذاكرة Rust، ويحاول تصفير المخزن عند الإفلات عنه (`Drop`). يمسح نسخ DPAPI المخصصة بواسطة النظام قبل `LocalFree`.
- `SealedDeviceSecret`: يمثل تشفيرًا محليًا يصلح للاستخدام في آلية تسجيل مستقبلية. **لا يُكتب حاليًا إلى القرص**.
- ثلاث اختبارات Windows/Rust: تشفير وفك اختبار صناعي، رفض ملف تالف، ورفض عبث بالنص المشفر.
- `w12-native-key-safety.test.mjs`: فحص ثابت لمنع إدخال واجهة تكشف المفاتيح أو تغيير قاعدة W05/W06.
- `run-w12-native-key-tests.ps1`: اختبار المرحلة فقط؛ لا يفتح SQLite أو MariaDB ولا يتصل بالسحابة.

## حدود الحماية

DPAPI ليس DRM؛ أي برنامج خبيث يعمل بصلاحيات مستخدم Windows نفسه قد يستطيع طلب فك التشفير من النظام. وهو لا يمنع استخراج ملفات JS أو فك بنية ملف EXE. مفاتيح خادم الإنتاج ومفاتيح التسعير/المدفوعات لا تدخل أصلًا إلى Windows Desktop.

لا تزال نسخة W05/W06 التجريبية تستخدم مفاتيح وقت تشغيل مؤقتة بدون تسجيل هوية جهاز حقيقي. لا نستبدل هذه المفاتيح أو نلمس أيًا من طلباتها المحفوظة (3 طلبات، 12 حدث انتظار). كما لا نغير بيانات W08/W10 على MariaDB المحلية.

## المطلوب قبل اعتماد W12 عمليًا

1. هوية جهاز موثوقة ومسار تسجيل من جهة الخادم، مرتبط بالمؤسسة والفرع والموظف.
2. تخزين مغلف داخل دليل Windows خاص بالتطبيق، مع صلاحيات ملفات مُدققة ورفض الروابط الرمزية وحماية من الكتابة المتزامنة أو فساد الحالة.
3. مسار تدوير وإبطال المفاتيح، ونسخ احتياطية ومزامنة بعد الانقطاع وفق سياسات المستخدم.
4. ضمان ألا ترجع أوامر Tauri قيمة سرية إلى WebView وألا تسربها السجلات/الاستثناءات.
5. اختبار Rust فعلي على Windows 10/11، ثم مراجعة أمان مستقلة. لا يكفي فحص Node ثابت لاعتماد DPAPI.

## اختبار محلي واحد بعد استلام الفرع

```powershell
Set-Location "$env:USERPROFILE\Desktop\FOON-Windows-W05"
git fetch origin feat/foon-windows-w12-native-dpapi-20261019
git switch --track origin/feat/foon-windows-w12-native-dpapi-20261019
& ".\apps\desktop\run-w12-native-key-tests.ps1"
```

**لا تدمج أو توزع Windows NSIS من هذا الفرع قبل اكتمال مراجعة W11 وW12.** لا GitHub Actions، ولا اختبار MariaDB مرة ثانية، ولا اتصال بالإنتاج.
