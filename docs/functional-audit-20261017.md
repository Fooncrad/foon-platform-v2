# FOON V2 — سجل التدقيق الوظيفي الكامل

تاريخ الجرد: 2026-10-17. مرجع الأساس: `707ad17993027ebebc31f8a3fb6a521503400152` بعد دمج #74.

**التسجيل ذاتي من الواجهة العامة، والتفعيل المجاني مباشر دون ربط بموافقة الأدمن.** إنشاء النشاط يدويًا من الأدمن خيار إضافي.

هذا سجل نطاق واختبارات قبول، وليس ادعاء أن كل بند مفقود أو أنه اختُبر. لا يُغلق بند بمجرد وجود صفحة أو نجاح البناء.

الحالات: **مراجعة** = لم يكتمل تدقيقه التفصيلي؛ **عيب مثبت** = دليل كود محدد؛ **إصلاح قيد التحقق**؛ **اختبار محلي ناجح**؛ **تحقق إنتاج معلق**.

قاعدة قبول كل بند: الحفظ وإعادة القراءة، التعديل والأرشفة/الحذف حسب السياسة، الإدخال غير الصالح، التزامن، العزل بين الحسابات والفروع، الدور والباقة، العربية/الإنجليزية/الفرنسية والجوال 320px. لا تنفيذ رسائل أو مدفوعات حقيقية دون نطاق معتمد، ولا تعديل إنتاج ضمن الاختبار.

أي تحقق يحتاج إنتاجًا أو مفاتيح خارجية يبقى معلقًا صراحة، مع إكمال العمل المستقل الممكن. التحقق محليًا أولًا ثم طلب دمج يدوي. لا دمج أو نشر تلقائي.

## عزل الأدوار — توجيه المستخدم الأخير

الأدمن لإدارة المنصة؛ المالك والمدير لإدارة نشاطهما؛ الموظف لدوره وفرعه فقط؛ العميل لحسابه وطلباته. دعم النشاط والباقة وصلاحية الموظف شروط مستقلة. أزيل تجاوز Super Admin التلقائي في `requireTenantMembership`؛ أي دخول تشغيلي يحتاج عضوية فعلية. لا توجد جلسة دعم بانتحال المالك ضمن هذه الدفعة. ثبت محليًا منع ستة أدوار موظفين من الشراء والمكتبة وواجهة العميل، مع إبقاء العمل المسموح وعزل النشاط الآخر. الأدوار المتخصصة الجديدة لكل قطاع (فني، موظف صالون، عامل خدمة وغيرهم) ما زالت تحتاج تدقيق النموذج والمخطط ومنحها، ولا تُغلق بهذا الاختبار.

## الدفعة الحالية

تفاصيل الباقات والعزل في `docs/activity-plans-and-role-isolation.md`. يحتاج الكود الجديد الترحيل 0093 قبل تشغيله. لا ترحيل إنتاج ولا إرسال بريد أو دفع حقيقي ضمن التحقق المحلي. باقي نقاط هذا السجل ما زالت مفتوحة حتى تُراجع واحدة واحدة.
